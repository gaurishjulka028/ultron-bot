Privacy Policy and Terms of Service

ULTRON is a multipurpose Discord bot for moderation, giveaways, music, welcome messages and server tools. This page explains what data it handles and the rules for using it.

What ULTRON stores

ULTRON keeps only what its features need. Discord IDs are stored as plain text identifiers.

What ULTRON uses but does not store

  • Member join events. With the Server Members intent, ULTRON sees a new member's ID, username and avatar at the moment they join. It uses them to post the welcome message and give the auto-role. It does not keep a list of members.
  • Message content for AutoMod. If a server turns AutoMod on, ULTRON reads the text of new messages in that server while it checks them for spam, links, Discord invites, excessive capital letters, mass mentions and blocked words. The text is checked in memory and is not saved. If a message breaks a rule, it is deleted, and the log channel entry records who, where and which rule, not the message text. Members with Manage Messages are never checked.
  • Moderation actions. Bans, kicks, mutes and similar actions are posted to the log channel the server chose. They live in that server's channel, not in ULTRON's database, except for warnings above.
  • Voice state. To play music, ULTRON sees which voice channel a member is in. Voice session details and the song you search for are sent to the music server (Lavalink) that streams the audio.
  • Command input. What you type into a slash command is used to answer that command and is then discarded.
  • Error logs. If something breaks, the host records the command name and an error message, which may include IDs. These are kept for a short time for debugging.

What ULTRON does not collect

  • Direct messages, or message text for any purpose other than AutoMod checks.
  • Online status, activity or presence.
  • Email addresses, phone numbers, payment details or real names.

ULTRON does not sell or rent data, show advertising, or build profiles of members.

Who else handles data

  • Discord delivers all events and messages and has its own privacy policy.
  • Music servers. Audio is resolved and streamed by Lavalink nodes, some of which are run by third parties, and they fetch audio from sources such as YouTube. They receive the search text and the voice connection details they need to play audio.
  • Hosting provider. ULTRON runs on a server that holds its database and logs.

Your choices and deletion

  • Server admins can turn off welcome messages, auto-role and logging with /setup disable, and remove a member's warnings with /clearwarns.
  • Removing ULTRON from a server stops all processing for that server.
  • To have the stored data for a server or for yourself deleted, ask in the support server. Requests are handled within 30 days.

Children

Discord requires users to be at least 13 (or the minimum age in their country). ULTRON does not knowingly collect data from anyone younger.

Security

The bot's access token and database are kept private on the host and are never published. No system is perfectly secure, so we limit what is stored to reduce what could be exposed.
